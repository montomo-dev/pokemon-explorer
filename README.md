# Pokemon Explorer

[PokeAPI v2](https://pokeapi.co/)(ポケモンのデータを返す無料のオープンAPI)を使った、ポケモン検索ビューアと APIドキュメントの1ページアプリです。

## タブ

- **Explorer**: 名前か番号で検索、一覧のページ送り、詳細(アビリティなど)の表示
- **API Docs**: PokeAPI v2 の主要エンドポイントを日本語で整理。「Try it」ボタンでその場でAPIを叩けます

## 使い方

`index.html` をブラウザで開くだけです(PokeAPIへの通信のためネット接続が必要)。ビルド不要。
