PokeAPI v2 ドキュメント

PokeAPI はすべての Pokemon データを提供するオープン RESTful API です。 認証不要・レート制限なし（フェアユース推奨）。 取得したリソースはローカルにキャッシュしてご利用ください。

Base URL: https://pokeapi.co/api/v2/
